# odin-recipes
This is just a basic recipe site that I'm making as a project of the Introductions course of The Odin Project.

It's the very first project TOP has awaiting at the end of the HTML Foundations module of the said course and initially, I'm only creating the layout and working with the structure of the website using HTML as instructed there.

This first attempt is intended to build on our HTML chops that we picked up previously in the module as its purpose is only to refine our existing knowledge up to this point— requiring us to have a general idea only on things such as the boilerplate, text and list elements, linking between multiple webpages, implementing images, and a few other conventions that we're going to build upon before we revisit it during the CSS Foundations module.
